# 1주 MVP 완성 계획

구현 코드는 포함되어 있습니다. 다음 일정은 직접 실행·검증하고 자신의 설명과 데모로 완성하기 위한 순서입니다.

| 날짜 | 할 일 | 완료 조건 |
|---|---|---|
| Day 1 | 문제 정의와 범위, 데이터 계약 읽기 | 세 검색 방식과 제외 범위를 자신의 말로 설명 |
| Day 2 | Docker 실행, 합성 데이터/단위 변환 확인 | seed 완료, readiness 200 |
| Day 3 | Structured 질의와 반례 실행 | 12개 환자 포함/제외 이유 설명 |
| Day 4 | Vector와 Hybrid 실행 | 환자·입원·시점 필터 및 근거 확인 |
| Day 5 | PostgreSQL 통합 테스트, 실제 모델 평가 | CI 통과, 실제 evaluation.json 보관 |
| Day 6 | 실패 결과 분석, 모델 SHA 고정 | 부정문/언어별 실패와 개선 가설 기록 |
| Day 7 | GitHub 게시, README 스크린샷, 3분 데모 | 재실행 가능한 repo와 실제 측정값 공개 |

## 완료 기준

- 새 환경에서 `docker compose up --build -d api` 실행 성공
- 세 검색 endpoint의 응답에 근거와 조회 시점 포함
- 퇴원/미래/재입원/미확정/단위 변환 반례 테스트 통과
- PostgreSQL 통합 테스트를 skip 없이 실행
- 실제 모델 평가 결과 기록; 목표 미달이면 결과와 한계를 그대로 명시
- `.env`, 모델 캐시, 실제 환자 정보 없이 GitHub에 게시

## 다음 버전

환자별 근거 타임라인 → assertion(부정·과거·가족력) 처리 → 더 큰 평가셋 → 자연어 조건 파싱 → 인증/읽기 전용 DB 계정 → 관측 지표 → AWS 배포 순서로 확장할 수 있습니다.
